# 🌐 Link Studio Hub (QR 코드 & URL 단축 웹 서비스)

> **Link Studio Hub**는 긴 URL을 간결한 단축 링크로 실시간 변환하는 **URL 단축 서비스**와 모바일 스캔용 **QR코드 생성 및 고화질 JPG 다운로드 서비스**를 통합 제공하는 모던 웹 애플리케이션입니다.

---

## 📌 1. 프로젝트 개요

- **프로젝트명**: Link Studio Hub (QR코드 생성 & URL 단축 웹 플랫폼)
- **주요 기능**:
  1. **QR코드 생성기 (`/url2qr`)**: URL 입력 즉시 고화질 QR코드 렌더링 및 JPG 이미지 원클릭 다운로드
  2. **URL 단축기 (`/urlShort`)**: OpenAPI 연동을 통한 실시간 URL 단축, 입력값 감지 스마트 버튼 비활성화, 원클릭 클립보드 복사 및 알림 피드백
  3. **통합 허브 & 내비게이션**: 상단 스위치 탭('QR코드' / 'URL단축')을 통해 두 서비스 간 자유로운 이동 지원
- **디자인 컨셉**: 모던 다크 글래스모피즘(Dark Glassmorphism), 네온 글로우 오빗 애니메이션, 반응형 레이아웃

## 📋 3. 상세 기능 명세서 (Functional Specification)

### 3.1. 통합 내비게이션 및 허브 (Main Hub & Navigation)
| 항목 | 기능 설명 | 세부 구현 내용 |
| :--- | :--- | :--- |
| **F-01** | 서비스 전환 내비게이션 버튼 | 모든 페이지 상단 헤더에 **'QR코드'** 버튼과 **'URL단축'** 버튼 제공 |
| **F-02** | QR코드 버튼 연결 | 'QR코드' 버튼 클릭 시 `url2qr/index.html`로 부드럽게 화면 이동 |
| **F-03** | URL단축 버튼 연결 | 'URL단축' 버튼 클릭 시 `urlShort/index.html`로 화면 이동 |
| **F-04** | 서비스 허브 대시보드 | 루트 `index.html`에서 두 서비스의 주요 특징 카드 및 원클릭 바로가기 제공 |

### 3.2. URL 단축 서비스 (`/urlShort`)
| 요구사항 번호 | 기능명 | 기능 명세 및 동작 원리 |
| :--- | :--- | :--- |
| **3-1** | UI 컴포넌트 구성 | • **URL 입력창**: 단축 대상 긴 URL 입력 (`input[type="url"]`)<br>• **단축하기 버튼**: OpenAPI 호출 트리거 버튼 (`button#shorten-btn`)<br>• **읽기 전용 출력 상자**: 결과 단축 URL 표시 (`input[readonly]#short-url-output`)<br>• **복사 버튼**: 클립보드 복사 트리거 (`button#copy-btn`) |
| **3-2** | 스마트 버튼 비활성화 | • 입력 필드가 비어있으면 '단축하기' 버튼을 `disabled` 처리 (회색 비활성 스타일 및 커서 차단)<br>• 1글자 이상 입력 감지(`input` 이벤트) 즉시 보라색 그라디언트 활성화 상태로 전환<br>• 클리어(X) 버튼을 눌러 내용 초기화 시 자동으로 다시 비활성화 |
| **3-3** | OpenAPI 실시간 단축 | • '단축하기' 클릭 또는 Enter 입력 시 `is.gd` OpenAPI (`https://is.gd/create.php?format=json&url=...`) 비동기 호출 (`fetch`)<br>• 로딩 인디케이터(스피너 및 '단축 생성 중...' 텍스트) 애니메이션 표시<br>• API 응답 수신 즉시 읽기 전용 상자에 단축 URL(`https://is.gd/xxxx`) 렌더링 및 하이라이트 효과<br>• 장애 대비 다중 폴백(v.gd, TinyURL) 지원으로 무중단 가용성 보장 |
| **3-4** | 자동 복사 및 알림 피드백 | • '복사' 버튼 클릭 시 브라우저 Clipboard API로 단축 URL 자동 복사<br>• 복사 성공 시 화면 하단에 **'복사하였습니다'** 토스트 알림창 팝업 노출 (3초 후 자동 페이드아웃)<br>• 복사 버튼 텍스트가 일시적으로 '✓ 복사됨!'으로 변경되어 시각적 피드백 제공 |
| **부가 UX** | 서비스 간 상호 연계 | • 단축 완료 후 **'이 단축 URL로 QR코드 만들기'** 버튼 클릭 시, 단축된 링크를 파라미터(`?url=...`)로 넘겨 QR코드 생성 페이지에서 즉시 QR코드 자동 생성 |

### 3.3. QR 코드 생성 서비스 (`/url2qr`)
| 항목 | 기능명 | 기능 명세 및 동작 원리 |
| :--- | :--- | :--- |
| **Q-01** | 실시간 QR 생성 | URL 입력창에 주소를 입력하고 확인을 누르면 중앙에 QRCode.js로 240x240 해상도 QR코드 렌더링 |
| **Q-02** | 인스턴트 JPG 저장 & 경로 지정 | 렌더링된 QR코드 카드를 클릭하면 File System Access API (`showSaveFilePicker`)를 통해 사용자가 저장할 폴더 경로를 직접 선택할 수 있는 '다른 이름으로 저장' 대화상자가 표시되며, 미지원 환경에서도 고화질 바이너리 Blob을 통해 안전하게 로컬 JPG 다운로드가 수행됩니다. |
| **Q-03** | 인터랙티브 화면 전환 | QR코드 생성 시 메인 레이아웃이 상하로 전환되며 다운로드 안내 오버레이 활성화 |

## 🛠️ 4. 기술 스택 및 환경
- **프론트엔드 코어**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Custom Properties / Flexbox & Grid)
- **아이콘 및 폰트**: Font Awesome 6.5.1, Google Fonts (Plus Jakarta Sans, Noto Sans KR)
- **라이브러리**: QRCode.js v1.0.0
- **단축 URL OpenAPI**: is.gd REST API (CORS 공식 지원) + v.gd / TinyURL Fallback

## 🚀 5. 실행 및 테스트 방법
1. 프로젝트 루트 폴더의 `index.html` 파일을 브라우저(Chrome, Edge 등)로 직접 열거나 로컬 웹 서버로 구동합니다.
2. 메인 페이지에서 **'QR코드'** 또는 **'URL단축'** 버튼을 클릭하여 각 기능으로 이동합니다.
3. 상단 헤더의 스위치 탭을 통해 두 서비스 간 실시간 이동이 가능합니다.
